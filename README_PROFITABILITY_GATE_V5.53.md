# V5.53 Edge / Profitability Gate

V5.53 menambahkan filter kualitas untuk AUTO berdasarkan outcome signal yang sudah CLOSED.

- Minimum sample sebelum edge dipakai.
- Mengutamakan scope side + regime + S/R bila sample mencukupi.
- Mengukur hit rate, average Realized R, profit factor, dan recent average R.
- AUTO ditahan jika edge historis konsisten negatif atau data belum cukup.
- Manual BUY/SELL tetap tidak diblokir.
- Tidak ada jaminan profit; statistik historis tidak menjamin hasil berikutnya.
