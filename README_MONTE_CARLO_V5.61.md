# V5.61 — Monte Carlo Risk Test

Stress-test urutan realized-R historis dengan bootstrap resampling.

- 2.000 simulasi deterministik per sample/risk input.
- Mengukur final return percentile, maximum drawdown, losing streak, dan frekuensi simulasi melewati DD 20%/30%.
- Minimum 20 CLOSED outcomes.
- Tidak mengubah signal, leverage, SL/TP, atau AUTO TRADE.
- Hasil bukan prediksi atau jaminan profit; gunakan sebagai stress test risk-per-trade.
