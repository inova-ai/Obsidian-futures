# Obsidian Futures V6.00 — Trading Control Center

V6.00 adds a single Control Center for readiness, current decision context, data integrity, simulator risk, strategy freeze, safety gate, and explicit human review.

## Safety
- Simulation/review only.
- Real order automation remains disabled by the control gate.
- Human Review records a timestamp only; it does not open or close trades.
- Export contains the current control state for audit.
