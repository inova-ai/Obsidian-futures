# V5.50 — Strategy Intelligence Layer

Adds an explainable historical setup layer on top of V5.49.

## Features
- Active setup context: side, market regime, S/R context, momentum bucket, readiness.
- Similar historical setup matching.
- Historical hit-rate and realized-R for matching setups.
- Pattern performance ranking and patterns to watch.
- Performance by BUY/SELL and market regime.
- Status: SUPPORTED / MIXED / WEAK / LOW SAMPLE / NO MATCH.

## Safety
This is an analytical layer. It does not automatically change BUY/SELL, leverage, SL/TP, AUTO TRADE, or live strategy parameters. Historical hit-rate is not a forecast or guarantee.
