# V5.84 — Pre-Trade Checklist

Adds a unified pre-trade checklist for DATA, REGIME, EDGE, R/R, RISK, PORTFOLIO, VALIDATION, SAFETY and EXECUTION.

READY means all critical checks pass. BLOCK means a critical guard failed. WAIT means non-critical conditions still need confirmation. High volatility can downgrade READY to WAIT.

The checklist is a guard/observability layer; it does not predict price or guarantee profit.
