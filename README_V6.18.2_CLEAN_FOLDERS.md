# V6.18.2 — Clean Folder UI

Built directly from the uploaded V6.18 Final Trial ZIP.

This release changes UI organization only:
- AI Signal modules are grouped into four accordion folders.
- Entry/Execution, Indicator, and Market Data are grouped.
- Live status and Position/Auto Trade are grouped.
- Only one sibling folder is open at a time.
- Existing element IDs are preserved so application logic can continue updating them.
- No LIVE order capability is enabled by this UI change.
- Chart/application logic is not replaced.
