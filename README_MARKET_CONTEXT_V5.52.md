# Obsidian Futures V5.52 — Market Context Engine

Adds an explainable market-context layer for structure, volatility, breakout/rejection, choppiness, and activity.

## Guardrails
- Advisory only; does not change BUY/SELL automatically.
- No automatic leverage, SL/TP, or AUTO TRADE changes.
- Breakout/rejection labels use current OHLC data; activity uses volume as a market-activity proxy.
- Context score is a descriptive composite, not a probability of future price movement.
