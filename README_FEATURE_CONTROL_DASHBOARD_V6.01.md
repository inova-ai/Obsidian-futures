# V6.01 — Feature Control Dashboard

Visible UI layer for the previously implemented V5.90–V6.00 modules.

## What changed
- Added a dedicated **Dashboard** tab as the first bottom tab.
- Added 12 visible feature cards with status and **BUKA** buttons.
- Added live summary cards for data quality, paper sample, simulator drawdown, safety gate, strategy freeze and real-order automation state.
- Added current system-state checklist.
- Dashboard refreshes while active.
- Mobile responsive layout for Android-sized screens.
- Existing modules remain available in their original tabs.

## Safety
The dashboard is informational/control UI. It does not enable real-order automation and does not guarantee trading results.
