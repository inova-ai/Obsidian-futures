# V5.57 — Strategy Research Lab

Research-only layer using closed signal outcomes already recorded by the application.

- Chronological 70% train / 30% out-of-sample split.
- Tests score, momentum, readiness and combined filters.
- Requires minimum OOS/train samples before ranking candidates.
- Overfitting guard holds weak or unstable candidates.
- No automatic changes to BUY/SELL, leverage, SL/TP or AUTO TRADE.
- Results are historical research, not a guarantee of future profit.
